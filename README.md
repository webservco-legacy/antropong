# AntroPong

The one-page site of AntroPong, the anthology of my fanzine (2013 to 2014): the first page, a hidden download page for
the zine PDFs, and the placeholder of 2014 while the blog was set up. A historical archive, kept read-only: the site's
code as it ran then, not maintained.
